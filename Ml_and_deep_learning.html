Module 1 · Foundations

Gradient descent & linear regression

Learning means minimizing a loss. For a line ŷ = wx + b, the mean squared error is a bowl; the gradient points uphill, so we step the opposite way, scaled by the learning rate η.

L = (1/n) Σ (wxᵢ + b − yᵢ)² · w ← w − η ∂L/∂w · b ← b − η ∂L/∂b
Data (true line: y = 2x + 1) and the current fit
Training loss, log scale
Try: push η above ~0.9 and watch the loss explode. Drop it to 0.001 and see how slowly it crawls. Raise noise — the loss floor rises, because noise can't be fit away.
Module 2 · Generalization

Bias, variance & regularization

A model that nails training data may fail on new data. Fit a polynomial of degree d to noisy samples of sin(3x). Too low: underfit (high bias). Too high: it memorizes noise (high variance). Ridge regularization λ penalizes large weights to tame this.

w* = (ΦᵀΦ + λI)⁻¹ Φᵀy test error = bias² + variance + irreducible noise
Filled dots: train · hollow: test · line: model
Error vs degree (log). Orange = test, indigo = train. Marker = current degree
Try: set samples=15, degree=12 and watch test error spike. Now slide λ up — the wiggles vanish. Add more samples and see overfitting shrink without regularization.
Module 3 · Optimization

The optimizer race

Real loss surfaces are ill-conditioned: steep in one direction, flat in another. Four optimizers start at the same point on the same surface. Momentum accumulates velocity; RMSprop rescales by recent gradient size; Adam does both.

Adam: m ← β₁m + (1−β₁)g · v ← β₂v + (1−β₂)g² · θ ← θ − η m̂/(√v̂ + ε)
Contours of the loss. SGD · Momentum · RMSprop · Adam
Try: condition number = 30 with a small η: SGD zig-zags while Adam glides. Add bumpiness to create local minima and see who gets trapped.
Module 4 · Deep Learning

Neural network playground

A network stacks linear maps and non-linear activations, learning a decision boundary by backpropagation: the chain rule applied layer by layer. Without non-linearity, depth adds nothing — depth only matters because of activations.

aˡ = σ(Wˡaˡ⁻¹ + bˡ) · δˡ = (Wˡ⁺¹ᵀ δˡ⁺¹) ⊙ σ′(aˡ) · ∂L/∂Wˡ = δˡ aˡ⁻¹ᵀ
Decision boundary (blue/orange) over training points
Train loss (indigo) vs held-out test loss (orange)
Try: Spiral + 1 layer × 4 neurons fails; 3 layers × 8 succeeds. Set noise high with a big net and no L2: train loss ↓ while test loss ↑ — overfitting. Switch to sigmoid and watch training slow (vanishing gradients).
